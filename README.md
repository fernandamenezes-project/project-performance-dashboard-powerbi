

# 📊 Dashboard de Performance de Projetos e Times

## 🎯 Objetivo

Criar um dashboard para acompanhamento de indicadores de performance de times e projetos, com foco em produtividade, controle de atividades e análise de entregas.

---

## 🚨 Problema

Dificuldade em acompanhar a performance do time e dos projetos de forma centralizada, com baixa visibilidade sobre:

* andamento das tarefas
* esforço dedicado
* produtividade por sprint e projeto

---

## 💡 Solução

Desenvolvimento de um dashboard utilizando Power BI, consolidando dados de tarefas extraídas do Jira para análise de indicadores estratégicos.

---

## 🛠 Ferramentas utilizadas

* Power BI
* Jira
* Excel (tratamento de dados)

---

## 📊 Indicadores de Time

* Quantidade de tasks no Jira
* Horas gastas por projeto
* Horas gastas por task
* Story points totais por sprint
* Story points concluídos por sprint
* Histórico de horas trabalhadas
* Histórico de story points
* Resumo detalhado das tasks

---

## 📈 Indicadores de Projeto

* Total de horas por projeto
* Total de story points por projeto
* Quantidade de atividades concluídas
* Quantidade de cards por status ao final de cada sprint
